OVERRIDES
This is the pathfinding bar — a bunch of buttons and tools to help you find your way through the station. There are a total of 3 tools on this bar.
  • Filters determines what type of parts you can select on the station (like stairs, platform sections, etc)
  • Overrides are optional buttons you can enable to affect what paths you navigate through the station (like accessibility only navigating).
    *If you don't see the override bar, it simply means that there are no optional buttons that exist for this station.*
  • Start/End/Find Route are buttons where you select which part of the station you want to go from (start) and to (end). You need to select a start and end destination for the find route button to work.
